# Звонок Молнии Маквину

Экран входящего вызова, который открывается на телефоне или планшете. Брат жмёт
зелёную трубку — и разговаривает голосом с Маквином (или Доком Хадсоном).

Работает так: браузер распознаёт речь → Claude отвечает в характере персонажа →
Fish Audio озвучивает ответ его голосом → браузер проигрывает. И так по кругу,
пока не нажать красную трубку.

---

## Настройка — уже сделана

**Голос работает прямо сейчас.** Ключ Fish Audio создан (имя ключа на сайте —
`zvonok-makvinu`) и лежит в `.env`. Модель `s2.1-pro-free` бесплатна для
разработчиков, баланс не нужен.

**Мозги пока локальные.** Ключа Anthropic нет, поэтому реплики подбирает
`brain.js` — банк фраз Маквина с подхватом ключевых слов (гонки, Мэтр, Салли,
Док, игры, грусть, сказка и т.д.). Для дошкольника этого хватает: персонаж
узнаётся по голосу и манере, а разговор держится на встречных вопросах.

### Апгрейд до настоящего диалога (по желанию)

Тогда Маквин будет отвечать на что угодно, а не по банку фраз:

1. https://console.anthropic.com/settings/keys → **Create Key**
2. Пополни баланс на пару долларов (детский диалог стоит копейки)
3. Впиши ключ в `.env` в строку `ANTHROPIC_API_KEY=`
4. Перезапусти сервер

Сервер сам переключится — при старте он пишет, какие мозги использует.
Персонаж Дока Хадсона (`CHARACTER=doc`) осмысленно работает только с этим
ключом: банк фраз написан под Маквина.

## Запуск

```bash
npm start
```

Открой в **Google Chrome**: http://localhost:3000

Chrome нужен потому, что распознавание речи (Web Speech API) работает только в
нём. Первый раз он спросит доступ к микрофону — разреши.

---

## Как дать телефон брату

Сервер крутится на твоём компьютере. Чтобы открыть страницу с телефона, оба
устройства должны быть в одной Wi-Fi сети:

1. Узнай IP компьютера:
   ```bash
   ipconfig getifaddr en0
   ```
2. На телефоне открой `http://<этот-IP>:3000` в Chrome.

⚠️ Микрофон в браузере работает только на `localhost` или по `https`. По голому
IP Chrome доступ к микрофону не даст. Варианты:

- **Проще всего**: открыть на самом компьютере (`localhost` работает всегда) и
  дать брату ноутбук или планшет с этой страницей.
- **Если нужен именно телефон**: пробросить туннель, например
  `npx localtunnel --port 3000` — он выдаст https-адрес, на котором микрофон
  разрешён.

## Как поменять персонажа

В `.env`:

```
CHARACTER=doc      # Док Хадсон вместо Маквина
```

## Как поменять голос

Найди голос на https://fish.audio/ru/app/discovery/, открой его страницу — ID
будет в адресе: `fish.audio/ru/app/m/<ID>/`. Впиши в `.env`:

```
FISH_VOICE_ID=<ID>
```

Сейчас используются:

| Персонаж | Голос из библиотеки | ID |
|---|---|---|
| Молния Маквин | «Дерзкий Парень» — молодой, энергичный, дружелюбный | `6ada82e315e648b6a30a2e2210844cbf` |
| Док Хадсон | «мориарти» — низкий, спокойный, авторитетный | `b4b3cd5e89cc4fb682301b43e627d5ef` |

Это не клоны актёров озвучки — это подходящие по характеру голоса из публичной
библиотеки fish.audio. Характер персонажа задаётся промптом в `app.js`.

---

## Как поменять характер персонажа

Всё в `app.js`, объект `CHARACTERS` — там текст `system` для каждого
персонажа и первая фраза `greeting`. Правь прямо в тексте, перезапусти сервер.

## Если что-то не работает

| Симптом | Причина |
|---|---|
| «Голос персонажа недоступен», говорит робот | Не задан или неверен `FISH_API_KEY`, либо кончился баланс. Точная ошибка — в терминале, где запущен сервер. |
| «Распознавание речи есть только в Chrome» | Открыто в Safari или Firefox. Нужен Chrome. |
| «Микрофон запрещён» | Нажми на иконку слева от адреса → разреши микрофон → перезагрузи страницу. |
| Не отвечает, ошибка в терминале про 401 | Неверный `ANTHROPIC_API_KEY`. |
| Не отвечает, ошибка про credit balance | Пополни баланс в консоли Anthropic. |
